# 시스템 규칙 — 수치·공식·불변식

> **규칙 자체의 정본이다.** 여기 적힌 수치와 판정식이 옳고, 다른 문서가 어긋나면 이 파일이 맞다.
> 판별: *이 줄에 숫자나 판정식이 있는가?* — 있으면 여기, "왜"가 붙으면 `design-structure.md`.
>
> 근거는 쓰지 않는다. 왜 이 값인지는 `design-structure.md`가 답한다.
> 코드 심볼·경로·`SAVE_SCHEMA`는 `CLAUDE.md`가 답한다.

## 화면

- **모바일 가로모드 기준** (≈844×390). 미디어 쿼리는 `min-*` 확장 방향으로만 쓴다
- 모바일 **가로 전용.** 세로 레이아웃 없음 — 세로 진입 시 회전 유도 화면만
- **스크롤 금지** (페이지·컨테이너 모두). 예외: 이벤트 진행 중 백로그
- 긴 본문은 **문단 분절 + 입력 진행**. ADV 하단 창을 만들지 말 것
- **입력마다 문단 단위로 전환한다 — 덧붙임(NVL 누적) 없음.**
  이전 문단은 백로그로만 다시 본다
- 분절 = 문자열 배열 (원소 = 문단 = 입력 1회 = 화면 1회). `\n\n` 금지, 검증기가 검사
- 넘치는 본문에 "더 보여주기"·펼치기 UI를 만들지 않는다.
  한 문단 = 한 화면 재단(콘텐츠 규격, design §12)으로 해결한다
- 뷰포트 높이 `dvh`, `env(safe-area-inset-*)` 반영
- 백로그는 **문서 단위** — 지금 열려 있는 문서에서 이미 드러난 문단까지만.
  아직 드러나지 않은 문단은 백로그에도 없다.
  체인(도입 → 미니게임 → 결과)을 거슬러 올라가지 않는다
- 백로그는 버튼(터치/클릭)으로 연다. 열려 있는 동안 진행 입력은 받지 않는다
- 백로그는 세션 로컬. 저장하지 않는다

## 상태 값

- 구역 ID: d2 / d5 / d7. d5 = 서편 거주구역
- 정체 내부 0~10, 표시는 4밴드 파생: 정상(0~2) / 삐걱임(3~5) / 이상(6~8) / 한계(9~10)
- **밴드는 저장하지 않는다. 항상 파생**
- `기억` 0~4 (5단계). **보류 해제 전까지 0 고정.** 단계별 관문어는 design §3-2
- **기술 5종.** 표기 순서 = 언어 3종(감류학·영창술·각인학) → 술법 2종(화염술·빙결술)
- 시작 등급은 4종 1, **빙결술만 0. 등급 0 = 미습득이며 능력치 패널이 숨긴다**
- 등급은 파생이다 — 콘텐츠 효과는 경험치에만 쓴다 (등급 직접 쓰기 경로 없음)

## 정체 정산

- **증감은 전부 일일 정산(`CLOSE_DAY`)에서만.** 콘텐츠 효과로 구역 정체를 움직이지 말 것
- 처리 성공 = −가중치 / 처리 실패 = 0 / 방치 = +가중치 / 자연 틱 = +1
- 하루치 합산 후 1회만 클램프(0~10)
- 카드별 가중치는 1~3
- 미니게임 성적의 **평가 귀속은 확정**, **정체 가중치 귀속은 미결 — 구현하지 말 것.**
  반영하게 되더라도 정산 시점은 일일 정산 유지
- 3밴드(이상) 미만에서는 이상 징후를 UI에 노출하지 않는다

## 프롤로그

- **새 게임은 프롤로그를 거쳐 DAY 01로 진입한다.** 이어하기는 거치지 않는다
- 스킵 없음 — 건너뛰기 UI를 만들지 않는다
- **완료를 저장하지 않는다. 첫 저장은 프롤로그 종료(DAY 01 진입) 시점** —
  타이틀의 "덮어쓰기"도 이때 일어난다. 도중 이탈 시 기존 세이브가 그대로 남는다
- 재열람에 등록하지 않는다 — 문서 ID 없음
- 그릇은 공통 오버레이 셸 (조우·다일·탐사 공용과 동일)
- **산문은 고정이다.** 기억·정체 어느 변형 축도 타지 않는다 —
  무조건 변형 하나만 (검증기가 검사)

## 근무 루프

- 1주 = 5근무일 + 2일 휴식. **현재 슬라이스는 1주차만 진행 후 엔딩으로 종결**
- 주간 마감: 금요일 일과 종료 → 주간 총평 장면(통지서 발행·재열람 등록) →
  주말 2일(택2) → 성적 분기 엔딩
- **해고는 총평 장면 없이 금요일 정산에서 곧장 엔딩.** 총평·주말은 유임자만 거친다
  (통지서 발행은 동일)
- **저녁 단계는 조건 맞는 장면이 있을 때만 선다.** 빈 저녁은 곧장 일일 정산
- 주말 슬롯 = 2일 × 택2. 활동은 단일 풀에서 뽑는다 (풀 구성은 콘텐츠)
- 하루에 한 구역 배치. 순회 없음
- 4주 사이클·승진·해고 판정식은 **1주차 완주 후 확장분 — 지금 구현하지 않는다**

## 카드

- **일반 카드 4종. 특수 카드는 시스템 전체 보류** (콘텐츠에 등장시키지 않는다).
  서사 체인·기억 관문·비밀 진행이 함께 정지. 체인 지원 코드는 유지
- **4종 = 미니게임 1:1** (검증기가 검사):

  | 카드 | 미니게임 |
  | --- | --- |
  | 마력회로 점검 | 파이프 퍼즐 (30초 — 규칙은 아래 "점검 미니게임") |
  | 구역 순찰 | 한붓 순찰 (30초 — 규칙은 아래 "순찰 미니게임") |
  | 자재 옮기기 | 블록 퍼즐 (30초) |
  | 불순물 소각 | 두더지 잡기 (20초 — 선별형: 태울 것 / 두어야 할 것. 규칙은 아래 "소각 미니게임") |

- **1:1의 유일한 예외: 최초의 불순물 소각 카드는 미니게임 전에 ENC-001이 선행**
  (최초 1회 한정)
- **인터랙션 순서: 얼굴 → 열기 → 짧은 도입 → 미니게임 → 결과 반영 산문.**
  산문은 반드시 미니게임 뒤. 결과가 산문을 바꾼다 (최소 3변형: 완수/부분/실패).
  실패 변형의 결과는 **현장이 아니라 다른 장소의 보고로 도착한다**
- **미니게임 시작 후 이탈(새로고침·종료)은 실패다.** 시작 시점이 저장되고,
  이어하기가 진행 중이던 카드를 실패로 반입한다 — 이탈 후 재도전 경로 없음
- 결과 화면에서 현장 묘사(정체 축)와 보고 문구(기억 축)는 **문단 분리**
- 존속: 당일 소멸, 다음 날 같은 얼굴로 재출현 가능. **미결 더미 미채택**
- **배부 3장(무작위) · 처리 2장.** 하루 3장은 종류가 겹치지 않는다 —
  적격 풀에 서로 다른 종류가 모자랄 때만 중복 허용
- **ENC-001 발생 전까지 소각 카드가 매일 1장 포함된다** (최초 대면 보장)
- **4종 전부 주 3회 이상 배부.** 기준은 배부(주 15장)이지 처리(주 10장)가 아니다
- 재발부 횟수를 UI에 표기하지 않는다
- 단서 축(없음/기억/기술)은 카드 하나에 하나만
- **일반 카드 4종의 무대는 지상층·수면 위.** 지하 진입 서술을 일반 카드에 두지 않는다
  (지하는 특수 카드 전용 — 특수 카드는 보류 중이므로 현재 도달 경로 없음)

## 점검 미니게임

- 판은 **정사각 격자** — 기본 4×4, 난이도(정체) 4부터 5×5. 제한 시간 불변
- **정답 경로가 곧 판 생성** (시드 기반, 런타임 난수 없음) —
  왼쪽 급원에서 오른쪽 종점까지. 같은 카드 재도전은 같은 판
- **급원·종점은 행렬 바깥 좌우에 표시한다** — 판의 일부가 아니며 회전 대상이 아니다
- 셀 탭 = 시계방향 90° 회전. 직선 관은 2회전 대칭으로 판정
- **장애물: 경로 밖 빈 칸에 시드 기반 배치 — 4×4에 2개, 5×5에 4개.**
  회전·통과 불가. 경로 생성이 먼저이므로 장애물이 해를 막을 수 없다
- 판정: 전 셀 정답 = 완수(도달 즉시 종료) / 절반 이상 정답 = 부분 / 그 외 = 실패
- 판 위의 장애물은 게임 말이지 아이콘이 아니다 — 아이콘 어휘 밖

## 순찰 미니게임

- 판은 **직사각 격자 + 장애물 칸** — 정사각 고정 아님. 장애물 칸은 밟을 수 없다
- **판 생성이 곧 정답 경로 생성** (시드 DFS, 런타임 난수 없음).
  경로가 지나지 않은 칸이 장애물이 된다 — 풀 수 없는 판은 존재할 수 없다
- 시작·끝 **맨해튼 거리 ≥ 판의 짧은 변** (이른 도착이 헐거워지는 것 방지)
- 이동은 상하좌우 인접, 밟은 칸 재진입 금지. 되돌기는 **직전 칸 1걸음 무르기**만
- 판정: **끝 도달 + 통행 칸 전부 답사 = 완수 / 끝 도달(미답사 잔여) = 부분 /
  끝 미도달(막다른 길·시간 만료) = 실패.** 끝 도달 즉시 종료
- 난이도(정체)는 **판 크기만** 키운다 — 제한 시간 불변

## 소각 미니게임

- 판은 **원형 배열 9포트**. 사각 격자 아님. 중앙에는 남은 시간만 표시
- 스폰은 **시드 기반 사전 계획** — 런타임 난수 없음. 간격은 비동기(불규칙),
  **유지시간 1.0초 고정, 동시 최대 5개**, 빈 포트에만 스폰
- 종류 배정은 **불순물 70% 고정 몫**(시드 셔플). 매 스폰 독립 확률 아님 —
  공급이 목표를 항상 웃돌아야 한다
- 점수: 불순물 소각 +1 / 마력 오인 소각 −1. **목표 20점, 도달 즉시 종료**
- 판정: 도달·오인 0 = 완수 / 도달·오인 ≥1 = 부분 / 시간 내 미달 = 실패
- **목표·점수를 UI에 표기하지 않는다.** 통과는 수치 없는 완료 문구 한 줄로만 알린다
- 난이도(정체)는 두 종류의 **색 구분 모호함만** 올린다 — 템포·유지시간 불변
- 판 위의 표적(불순물·마력)은 게임 말이지 아이콘이 아니다 — 아이콘 어휘 밖

## 평가

- **Perfect / Passed / Not Passed** 3종
- 장별: 완수→Perfect / 부분→Passed / 실패→Not Passed
- **주간 경계 합산식**: Not Passed가 처리 장수의 절반 이상 → 주 Not Passed /
  전 장 Perfect → 주 Perfect / 그 외 → 주 Passed
- 엔딩 분기는 같은 경계 공유: **주 Not Passed = 해고, 그 외 유임**
- 주간 합산은 금요일 시점 값 유지
- 통지서: 금요일 저녁 발행, 문서 ID로 재열람 등록, 완곡어 축을 탄다. 아이콘 없음

## 텍스트 렌더링

- **렌더링된 문장을 저장하지 않는다.** 저장 대상은 문서 ID와 상태값뿐
- **과거 문서도 현재 `기억` 값으로 재렌더링한다** (그때 값 렌더링 금지)
- 변형 축 분리: 완곡어 = `기억` 축(문서·보고서·카드 표면·보고 문구) /
  악화 = `정체` 밴드 축(현장 묘사·본문). **한 문서에 두 축을 동시에 쓰지 않는다**
- **지명은 치환자 대상이 아니다.** 오버레이 타이틀·고유명사는 `기억`·`정체`
  어느 축으로도 변형되지 않는다 — 앵커다
- 재열람 목록에서 `기억`으로 렌더링되는 것은 **얼굴 문구**다.
  카드 종류명은 아이콘 어휘와 1:1인 앵커이므로 어느 변형 축도 타지 않는다

## 아이콘

- **상태에 반응해 변하지 않는다**
- **어휘 크기 = 일반 카드 4종과 1:1.** 대응 대상은 카드 종류이지 얼굴 문구가 아니다
- 조우·평가 통지서에는 아이콘을 두지 않는다 (어휘 밖)

## 조우

- 하루 루프와 분리된 독립 리듀서. 종료 시 outcome별 효과만 세계 상태로 반입 —
  **조우 안에서 세계 상태를 직접 건드리지 말 것**
- 조우 상태는 저장되지 않는다
- **ENC-001**: 최초 불순물 소각 카드를 열 때 미니게임 **전에** 선행.
  설명형 — 행동·턴·판정 없음. 효과는 동요 +1.
  **성적 귀속은 미니게임 결과가 맡는다** (조우 outcome은 성적에 무관)
- 4행동×N턴 다단 구조는 폐기가 아니라 **향후 조우의 그릇**으로 코드에 유지
- 오버레이 셸은 **공통 셸** (조우·다일·탐사 공용)

## 비공개 수치

- **UI에서 감추는 것은 둘뿐: 정체 원값, 소각 미니게임의 점수·목표.** 밴드는 보인다.
  그 외 수치를 임의로 감추지 말 것

## 고도

- **게임오버·부활 경로를 만들지 않는다.** 고도는 실패 상태가 아니다
- 주간 루프 UI에 표기하지 않는다. 내부 수치로만 유지

## 세이브

- `{schema, state}` 봉투. 불일치 시 새 게임
- 스키마 변경 시 "렌더 문장 미저장" 제약을 매번 재확인할 것
