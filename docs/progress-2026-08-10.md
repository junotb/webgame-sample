## 1. 한 줄 요약

**화면의 문법이 바뀌었다.** 기준 화면은 모바일 가로모드(가로 전용)이고, 스크롤은
게임 전체에서 금지되며(유일한 예외: 백로그), 긴 본문은 Type-Moon계 비주얼 노벨의
**NVL 문법** — 입력 한 번 = 문단 하나, 종이가 차면 장 넘김 — 으로 읽는다.
결정부터 구현·검증까지 이번 세션에서 완료했다. 사양 문서는 `docs/ui-screen-spec.md` 신설.

## 2. Project Instructions에 반영 필요한 확정 사항

### 2-1. 화면 규격 (CLAUDE.md 「화면」 절 신설 — 전문 반영 권장)

- **모바일 가로모드가 기준 화면.** 기본 스타일은 짧고 넓은 화면(≈844×390),
  데스크톱은 `min-*` 쿼리로 확장. 종전의 데스크톱 기본 + `max-*` 축소는 폐기
- 모바일은 **가로 전용** — 세로 레이아웃을 만들지 않는다. 세로 진입 시 회전 유도 화면만
- **스크롤 금지.** 페이지·컨테이너 모두. 유일한 예외는 이벤트 진행 중
  **백로그**(이전 텍스트 보기) — 아직 미구현, 다음 작업 라인
- 긴 본문은 **문단 분절 + 입력(엔터·클릭·탭) 진행.** 참고 문법은 NVL
  (Fate/stay night · hollow ataraxia): 문단이 종이에 쌓이고, 차면 장이 넘어간다.
  **문서 스킨이 곧 텍스트 창** — ADV식 하단 대사창을 만들지 않는다
- 한 화면에 안 들어가는 정보는 "더 보여주기"가 아니라 **장 넘김**
- 뷰포트 높이는 `dvh`, 노치 세이프 에어리어(`env(safe-area-inset-*)`) 반영

### 2-2. 본문의 데이터 표현 — 문단 배열 (스키마 확정)

- 본문 성격의 텍스트(지시서 body, 스토리렛 body, 조우 intro)는
  **`ProseVariant` = 조건 + `paragraphs: string[]`.** 원소 하나 = 문단 하나 = 입력 한 번
- `\n\n` 같은 문자열 관례 금지 — 분절은 읽기의 박자를 정하는 콘텐츠의 명시적 결정이고,
  검증기가 지킬 수 있어야 한다 (빈 배열·빈 문단·문단 안 빈 줄 전부 로드 시점 거부)
- 제목·라벨은 종전 `TextVariant`(한 줄) 유지 — 두 타입은 변형 선택 규칙(첫 매치 우선)을 공유
- **콘텐츠 저작 지침: 문단은 한 화면(가로모드 세로 ≈330px) 기준으로 재단.**
  기존 본문 11곳은 공문 문구 / 현장 묘사의 어조 전환점에서 갈라 이행 완료

### 2-3. 분절 컴포넌트 규칙 (구현 계약)

- 선택지·판정 버튼은 **마지막 문단이 드러난 뒤에만** 나타난다 — 읽어야 고를 수 있다
- 진행 입력: 영역 클릭·탭, 포커스 무관 엔터·스페이스 (선택지 버튼 위에서는 비켜선다)
- 장 넘김은 **실측**: 문단이 종이(`max-height`/flex 높이)를 넘치면 그 문단부터 새 장.
  종이가 줄어들 때(선택지 등장, 뷰포트 변화)도 같은 규칙 (ResizeObserver)
- 처리 완료 문서의 재열람은 전 문단 즉시 공개(`revealAll`)

## 3. 구현 현황 (이번 세션, `docs/ui-screen-spec.md` §5 구현 순서 기준)

### 1단계 — 기반 ✅
- `viewport-fit=cover`, `vh → dvh` 전량 전환, 좌우 세이프 에어리어, 터치 타깃 33→42px

### 2단계 — 본문 배열화 ✅
- `ProseVariant` 신설, 4개 필드 전환, `selectProse` / `bindVariants` 제네릭 / `checkProse` 검증기
- 콘텐츠 본문 11곳 문단 배열 이행 (검증기가 이행 중 구 형식 잔재를 실제로 잡아냄)
- **SAVE_SCHEMA 6 → 7** — 발부 카드(`pendingOrders`)가 본문 사본을 품고 저장되므로.
  "콘텐츠 변경이라 세이브 무관"이라는 초기 판단은 **오판**이었고 사양 문서에 정정 기록
  (8/7 보고의 교훈 재확인: 상태 모양이 바뀌면 반드시 스키마를 올린다)

### 3~4단계 — 분절 컴포넌트 + 본문 교체 ✅
- `app/paged-copy.tsx` 신설 (2-3의 계약 전부), 전용 테스트 5건
- 열람 패널·사무소 장면·조우 intro 교체 — 조우는 intro 완독 후에만 관측 행동 노출

### 6~7단계 — 셸 잠금 + 서류함 장 넘김 ✅ (순서 앞당김 — 사용자 지시)
- `body 100dvh + overflow hidden`, 전 층(무대·패널·오버레이) flex 수납 재편
- 좁은 화면 1열 쌓임 제거 — **어떤 폭에서도 지도+열람 2단** (세로 쌓임은 무스크롤과 양립 불가)
- 지도 비율(4:3) 고정 폐기 — 남은 높이를 채운다 ("높이가 먼저")
- 서류함: 색인 4건/장 + 앞·뒷장, 본문도 분절 열람으로
- 세로 예산 재배분: 최근 기록·업무 종료를 지도 열 아래로, 열람 열이 전 행 사용
- **임시 축약 2곳**: 최근 기록 띠·정산 로그를 한 줄 말줄임으로 — 전문 복원은 백로그(5단계)의 몫
