# 미결 안건

> 배치: `docs/open-questions.md`
> 성격: 설계 결정이 필요하지만 지침·사양서 어디에도 자리가 없는 항목의 대기열.
> 결정되면 해당 절에 반영하고 **여기서 삭제한다.** 이 파일에 확정 사항을 남기지 않는다.
> 최종 갱신: 2026-08-06 (slice v3 세션 1~4 구현 완료 시점)

## A. 주간 평가식이 노후도 밴드의 사본이다

**현황** — 평가 = 금요일 종료 시점 배치 구역의 노후도 밴드(완벽/양호/염려/경고).

**문제** — 검증 목표 4("금요일이 무서운가")가 목표 1·2와 같은 것을 묻게 된다.
평가가 밴드의 단순 사본이면 "금요일이 무섭다"는 "노후도가 무섭다"와 구별되지 않고,
주간 루프가 독립된 압박 장치라는 근거가 사라진다.

**후보 해법** — 밴드에서 파생되지 않는 항을 하나 섞는다.
보고 누락 / 다일 이벤트로 인한 미제출 / 주목 / 재발부 누적 등.

**결정 시점** — **1주차 플레이 판정 이후.**
판정 4가 밋밋하면 원인이 이미 확정된 셈이고, 의외로 압박이 걸린다면 손대지 않는 편이 낫다.
지금 고치면 판정이 측정하려던 것을 측정하지 못한다.

**반영 위치** — 지침 1장 「근무·평가·배치」의 "현재 평가식은 슬라이스 판정용 임시식" 항목.

## C. 조우 수치 실측 튜닝

**현황** — 턴 수 4 / 진정 누적 임계 2 / 관찰 난이도 보정 −1, 전부 가안.

**판정 기준** — 조우 3~4회를 겪은 뒤에도 **매 턴 선택이 고민이 아니면 재설계.**
"관찰 → 관찰 → 태우기"가 항상 정답이면 다단 판정이 아니라 연출이다.

**관찰 항목** — 턴 소진(강제 이탈)이 실제로 발생하는가.
한 번도 발생하지 않으면 턴 4가 과하고, 매번 발생하면 행동 효율이 부족하다.

**결정 시점** — 1주차 플레이 판정과 동시.

**반영 위치** — `docs/phase0-slice-v3.md` 조우 절.

## D. 구역 고유명사 체계 — d5 확정, d2/d7 대기

**확정 (2026-08-07)** — **d5 = 서편 거주구역.** 도시 서쪽의 하위 거주구, 화자의 집이 있다.
특이 지형은 **하수도**: 회색 폭포(하수가 공중도시 밖으로 떨어지는 곳),
인공습지(하층민들이 하수를 정화하는 갈대밭). 지점명 반영 완료
(하수 7호 지선 / 하수 간선 분기실 / 인공습지 갈대밭 / 회색 폭포 배수 갱도 등).

**대기** — d2 / d7 이름과 특이 지형. 구역마다 특이 지형(호수/숲 등)을 두어
탐사 카드가 그 지형에 붙는 방향 (E와 연동). 배경은 **아케인펑크** —
마법 기운이 감도는 이름이되, 사람들이 실제로 부르는 이름의 결을 지킨다
("서편 거주구역"과 "회색 폭포"가 기준: 행정과 지형지물의 언어이지 서사의 언어가 아니다).

**반영 위치** — `app/ui-labels.ts` ZONE_LABELS + 콘텐츠 zoneMaps + 지도 에셋 라인.

## E. 구역 계통 분리·과락·승진 난이도 (4주 확장 제안)

**계기** — 승진으로 구역을 옮기면 난이도가 올라야 한다. 노후도 단일 지표로는
"더 어려운 구역"이 "숫자가 더 빨리 오르는 구역"밖에 안 된다.

**제안 — 노후도를 계통(系統)으로 분리한다.**

- 구역의 노후도 = 공통 계통 + **특이 지형 계통**의 묶음. 각 계통이 0~10, 4밴드 파생은 동일
  - 공통: 각인·등화 / 관로·압력
  - 지형: d5 = 하수·정화 (회색 폭포, 인공습지). 다른 구역은 호수/숲 등 (D와 연동)
- 탐사(survey) 카드와 조우 입구는 지형 계통에 붙는다 — 지형이 구역의 정체성이 된다
- CLOSE_DAY 정산은 계통별: 카드가 자기 계통에 −/+가중치, 자연 틱도 계통별

**주간 평가 = 평균 + 과락** (사용자 방향: "평균 혹은 하나라도 과락")

- 등급은 계통 밴드의 **평균**으로 매긴다
- 단, 어느 계통이든 **한계(9~10)에 닿으면 평균과 무관하게 「경고」** — 과락
- **게임 오버 = 해고.** 과락 상태로 금요일 종료 또는 사이클 내 경고 2회 → 해고.
  v3 원칙 유지: 실패 압박은 조직 인사가 전담하고, 고도·부활과는 무관하다

**승진 난이도 곡선** — 상위 구역일수록:

1. **계통 수 증가** (하위 2+1 → 상위 3+2). 슬롯은 2로 고정이므로 지켜야 할 저울만 늘어난다 —
   난이도의 원천이 수치 인플레가 아니라 트리아지 압박이 된다
2. 자연 틱 차등 (+1 고정 → 계통별 +1~+2)
3. 시작 노후도 상향
4. 떠난 구역은 돌아갈 수 없고, 그 방치가 도시 고도를 계속 갉는다 (v3 §2 참고 유지)

**미결** — 계통 수·명칭, 과락 임계(한계 진입 즉시인가 종료 시점인가), 해고 판정식,
"평균이 좋은데 한 계통만 방치"를 막을 추가 항 필요 여부.

**결정 시점** — 1주차 판정 통과 후, 4주 확장 스펙 수립 시.
`world:zones.*.decay` 상태 키가 바뀌는 큰 스키마 변경이므로 슬라이스에는 반영하지 않는다.

**반영 위치** — 4주 확장 스펙 + CLAUDE.md 상태 키 절.
