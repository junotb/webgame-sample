# 미결 안건

> 배치: `docs/open-questions.md`
> 성격: 설계 결정이 필요하지만 지침·사양서 어디에도 자리가 없는 항목의 대기열.
> 결정되면 해당 절에 반영하고 **여기서 삭제한다.** 이 파일에 확정 사항을 남기지 않는다.
> 최종 갱신: 2026-08-06 (slice v3 세션 1~4 구현 완료 시점)

---

## A. 주간 평가식이 노후도 밴드의 사본이다

**현황** — 평가 = 금요일 종료 시점 배치 구역의 노후도 밴드(완벽/양호/염려/경고).

**문제** — 검증 목표 4("금요일이 무서운가")가 목표 1·2와 같은 것을 묻게 된다.
평가가 밴드의 단순 사본이면 "금요일이 무섭다"는 "노후도가 무섭다"와 구별되지 않고,
주간 루프가 독립된 압박 장치라는 근거가 사라진다.

**후보 해법** — 밴드에서 파생되지 않는 항을 하나 섞는다.
보고 누락 / 다일 이벤트로 인한 미제출 / 주목 / 재발부 누적 등.

**결정 시점** — **1주차 플레이 판정 이후.**
판정 4가 밋밋하면 원인이 이미 확정된 셈이고, 의외로 압박이 걸린다면 손대지 않는 편이 낫다.
지금 고치면 판정이 측정하려던 것을 측정하지 못한다.

**반영 위치** — 지침 1장 「근무·평가·배치」의 "현재 평가식은 슬라이스 판정용 임시식" 항목.

## B. 성장(경험치) 시스템 도입 여부

**현황** — 콘텐츠 효과로만 기술·스탯이 오르고, 리듀서는 상승을 로그로 통보만 한다.

**권고: 일반 경험치를 신설하지 않는다.** 근거 둘.

1. 카드 처리량에 성장이 연동되면 "많이 처리 = 강해짐"이 되어 트리아지가 최적화 문제로 바뀐다.
   지침 1장이 명시적으로 막은 "최적해가 존재하는 위키 게임"이 숙련 축으로 되돌아온다
2. 성장 곡선은 시시포스 반복의 반대말이다. 매일이 같아 보여야 하는 게임에 우상향 막대가 생긴다

**대안 — 숙련은 조우에서만 오른다.**
굿 엔딩 조건 2(화염술·빙결술 숙련)와 조건 1(낮은 동요)이 반대로 당기는 것이 메나스 삼각의
핵심인데, 숙련이 조우 밖에서 오르면 삼각이 풀린다.
이미 `enc_burned_*` / `enc_soothed_*` 플래그가 남고 있으므로 **누적 개수 → 등급 승격** 형태면
새 자원 없이 닫히고, 결말 축과 숙련 축이 같은 데이터를 쓴다.

**미검토 지점** — 태움/재움 누적이 등급으로 승격되는 임계값, 그리고 한쪽으로 치우친 플레이가
다른 계열 숙련을 영영 못 올리는 것이 의도인지 여부(의도라면 결말 분기 재료가 된다).

**결정 시점** — 4주 확장 스펙 수립 전. 1주차 판정과는 독립.

**반영 위치** — 지침 1장 「핵심 시스템 장치」 + 결말 조건 절.

## C. 조우 수치 실측 튜닝

**현황** — 턴 수 4 / 진정 누적 임계 2 / 관찰 난이도 보정 −1, 전부 가안.

**판정 기준** — 조우 3~4회를 겪은 뒤에도 **매 턴 선택이 고민이 아니면 재설계.**
"관찰 → 관찰 → 태우기"가 항상 정답이면 다단 판정이 아니라 연출이다.

**관찰 항목** — 턴 소진(강제 이탈)이 실제로 발생하는가.
한 번도 발생하지 않으면 턴 4가 과하고, 매번 발생하면 행동 효율이 부족하다.

**결정 시점** — 1주차 플레이 판정과 동시.

**반영 위치** — `docs/phase0-slice-v3.md` 조우 절.

## D. 구역 고유명사 체계

**현황** — ID `d2` / `d5` / `d7` 그대로 노출 중. 명명 규칙 없음.

**제약** — 이름은 표면 층에 노출되므로 조직의 언어여야 한다.
구역명이 서사적이면(예: "잿빛 골목") 표면이 실제를 새기기 시작한다.
행정 명칭 계열(번호·방위·시설 기준)이 안전하다.

**연동** — `world:zones.*` 키와 `{zone}` 치환자는 이미 리네임 완료.
고유명사는 바인딩 시점에 값만 바뀌므로 스키마 변경 없이 나중에 채울 수 있다.

**결정 시점** — 1주차 판정 이후, 지도 UI 라인 착수 전.

**반영 위치** — 콘텐츠 템플릿 + 지도 에셋 라인.
