## 2. Project Instructions에 반영 필요한 확정 사항

### 2-1. 서사는 카드에 있다 (v3 §4 정정 — 가장 큰 설계 변경)

- **도시의 비밀(필수 서사)은 일과 중의 카드에서 알게 된다.** 저녁 사무소 장면은
  관계·선택 이벤트 전용으로 남는다. "일과 뒤에 비밀을 알아가는" 구조는 오답이었다
- 서사 카드는 `requirements`(플래그·기억·일차 조건) + `thread: true`로 표기되고
  정렬 맨 앞에 온다 — **근무 슬롯 2개를 놓고 일상 지시서와 경쟁하는 것이 핵심**
  (진실을 좇는 대가 = 오늘 하지 못한 일)
- 단서는 카드 **제목**(`TextVariant[]`)에 실린다. 단서 축은 3종:
  처음부터 구별 / **기억**이 오르면 구별 / **기술** 등급이 오르면 구별.
  카드 하나에 축 하나만, 섞는 것은 덱 수준에서
- 단서는 "여기 서사가 있다"고 말하지 않는다 — **퀘스트 표식 금지.**
  표면 분류 5종·아이콘 불변 원칙은 서사 카드에도 그대로 적용된다

### 2-2. 기술 경험치 확정 (전 보고의 미결 안건 → 결정)

- **경험치가 원본, 등급은 파생.** `skillXp` 저장, 등급 = min(7, 1 + floor(xp/8))
- 경험치는 **콘텐츠가 선택지별로 부여**한다 (리듀서 자동 지급 없음) —
  "많이 처리하면 강해짐"이 트리아지를 무너뜨리는 함정을 콘텐츠 저작권으로 회피
- 기억과 같은 비가역 값: 감소 효과는 타입·검증기·런타임 3중 차단
- UI는 경험치 바(다음 등급까지 채움)로 표기

### 2-3. UI 층위 5층 모델 (`docs/phase0-ui-layers.md` 신설)

- L0 타이틀(독립 화면) / L1 무대(구역 지도 + 상단 띠) / L2 참조 패널 /
  L3 진행 오버레이(일일 개시·사무소 장면·정산) / L4 통지
- 규칙: L2·L3 동시 표시 금지, L3는 L1을 덮고(지도는 뒤에 남되 비활성),
  L4만 L3 위에 쌓인다
- **L1의 중심은 구역 지도.** 지시서는 유지보수 지점 마커에 붙고,
  마커 **호버**(모바일은 탭)로 카드가 열린다 — 목록 스크롤이 아니라 지도가 책상이다
- 구 「도시 운용 원장」 폐기 → **내 능력치** / **도시 상태** 두 패널로 분리.
  재열람은 **서류함**(일기 색인) 패널

### 2-4. 세계 설정 — d5 확정, 배경 명명 원칙

- **배경은 아케인펑크.** 지명은 사람들이 부르는 이름의 결 —
  행정·지형지물의 언어이지 서사의 언어가 아니다
- **d5 = 서편 거주구역** (확정): 도시 서쪽의 하위 거주구, 화자의 집이 있다.
  특이 지형은 **하수도** — 회색 폭포(하수가 공중도시 밖으로 떨어지는 곳),
  인공습지(하층민들이 하수를 정화하는 갈대밭)
- 지점명 반영 완료: 하수 7호 지선 / 하수 간선 분기실 / 제3각인중계실 /
  인공습지 갈대밭 / 회색 폭포 배수 갱도 / 서편 가로등 열 / 자재 수령소 / 구역 사무소
- d2/d7 이름·특이 지형은 미정 (미결 D)

### 2-5. 표기 원칙 추가

- **재발부 횟수를 UI에 표기하지 않는다.** 난이도 보정은 유지, 표기만 제거
  (판정 1 "놀라는가"의 측정 전제 — 통보받은 것은 알아챈 것이 아니다)
- 시간 소모 표기: 내부 단위 "근무 1" 대신 **반나절 / 하루** (하루 = 슬롯 2)
- 판정 표기("각인학 · 72%")는 선택지 라벨과 중복되지 않게 분리
